Built-in principles

Useful defaults, without unnecessary weight.

01

Accessible by design

Semantic landmarks, visible keyboard focus, a skip link, strong contrast, and reduced-motion support are part of the baseline.

02

Privacy-respecting

No trackers, third-party fonts, remote scripts, forms, or analytics are loaded. The browser receives only the files needed for this page.

03

Easy to operate

A dependency-free validation and build step checks the site before GitHub Pages receives an allowlisted deployment artifact.
